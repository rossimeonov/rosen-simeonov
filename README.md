# Росен Симеонов — официален уебсайт

Личен уебсайт на Росен Симеонов, изграден с Vite, React и TypeScript.

## Локално стартиране

**Изисквания:** Node.js

1. Инсталирай зависимостите:
   `npm install`
2. Стартирай dev сървъра:
   `npm run dev`

## Build

`npm run build` — резултатът се записва в `dist/`.

## Деплой

Сайтът се деплойва през Vercel (виж `vercel.json` за rewrites и security headers).
